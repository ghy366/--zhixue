# 视频录制情况说明

## 录制方式

| 项 | 说明 |
|---|---|
| 驱动方式 | Playwright 驱动真实 Chrome 浏览器（系统 Chrome，有头模式）自动操作页面 |
| 分辨率 | 1920×1080（recordVideo size 显式指定） |
| 帧率 | 分段原始录像 25fps（Playwright screencast），**最终交付 MP4 统一转换为 30fps（ffprobe 实测 30fps）** |
| 格式 | 分段 WebM（VP9）→ ffmpeg 拼接转码 → **H.264 MP4**（主流播放器/答辩教室设备可直接播放） |
| 操作真实性 | 全部点击/输入/弹窗均为真实 UI 操作，业务结果由后端真实接口与 MySQL 事务产生；冲突拦截、容量拦截、候补排队均由业务规则实时触发，无预制提示图 |
| 后台注入 | 管理员开启第 1 轮后，由脚本调用**真实选课接口**模拟 12 名背景学生并发投分（计算机网络报满等），用于体现报名热度与容量约束；属于模拟多用户场景，非数据造假 |
| 剪辑原则 | 分段录制后按时间轴拼接，不删减失败/拦截过程；**拦截提示本身就是演示内容** |
