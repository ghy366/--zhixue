## 环境说明

- 前端 Vite 5174 / 后端 Spring Boot 8080 / MySQL zhixue_demo 独立演示库
- 演示数据与账号见《演示账号与密码.md》《演示数据说明.md》
- 录制方式：Playwright 驱动真实 Chrome（1920×1080 @30fps），无人工剪辑、无报错弹窗

## 未实现功能声明（视频如实规避，不做伪造）

- 管理员**自动排课算法**未实现：课程时间/教室/容量为管理员手工配置；系统在**学生选课侧**实时做冲突与容量校验，必修课由教学计划**自动排入课表**
- 无独立"教学班"实体：课程即教学班（课程自带教师/时间/教室/容量）
- 无单独"课表发布"动作：选课结算后学生课表自动呈现
